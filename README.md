# Phantasma.cpp
An ultra-optimized llama.cpp fork tailored for MoE architectures and advanced decoding techniques. Designed to squeeze maximum performance out of mid-range hardware, pushing Gemma 4 (26B/4B) up to 50 tok/s on an RTX 4060 over PCIe 3.0 using experimental Tree MTP (multi-token prediction in tree structures) and extreme hardware-level optimizations.

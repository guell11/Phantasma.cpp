Reproducible performance work starts with inputs that can be identified byte for byte. A benchmark corpus should preserve prompt ordering, content hashes, and tokenizer-derived lengths so two runs can prove they measured the same workload. Stable scenario identity then binds that corpus label to the model, batch size, context, tree shape, sampling policy, seed, backend, and device. This avoids silent changes in whitespace or prompt selection from being mistaken for a runtime improvement. Raw artifacts can later carry the identities without needing to duplicate prompt text.
